# Token Economics - Cost and Rate-Limit Budgeting

## Setup (VS Code terminal, inside this folder)
```powershell
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
## Run
```
python budget.py
python -m unittest test_budget.py -v
```
Edit the assumptions in `.env` and re-run for the what-if analysis (lab section 8).
